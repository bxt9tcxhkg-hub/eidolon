## Variant: Eidolon embodiment directions

### Design stance
Drei sichtbare Gestaltungsrichtungen, damit die Verkörperung nicht abstrakt bleibt: humanoid-operativ, maskenhaft-souverän, geistartig-systemisch.

### Key choices
- 3 klar getrennte Körper-/Gesichtsansätze
- animierte Bühnen statt Textbeschreibungen
- direkte Vergleichsleiste oben
- dynamische Empfehlung unten je Auswahl

### Trade-offs
- Stark bei: Vorstellbarkeit, Richtungsentscheidung, gemeinsame Designsprache
- Schwach bei: produktionsreifer UI-Integration in die bestehende Eidolon-Web-App

### Best for
- Die Frage, wie sichtbar, menschlich oder systemisch Eidolon als Agent wirken soll.
