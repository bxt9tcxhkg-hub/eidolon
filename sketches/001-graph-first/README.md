## Variant: Graph first

### Design stance
Das Projekt wird zuerst als Denk- und Abhängigkeitsraum verstanden; operative Tasks sind sekundär.

### Key choices
- Layout: großer zentraler Canvas, schmale Projektliste links, Details rechts
- Typography: kompakt, technisch, klar
- Color: dunkles Runtime-Theme mit Statusfarben
- Interaction: Klickbare Knoten, Umschalter für Layer und Fokus

### Trade-offs
- Stark bei: Strategie, Architektur, Abhängigkeiten, Blocker sichtbar machen
- Schwach bei: schnellem Task-Schieben im Alltag

### Best for
Architekturarbeit, Produktplanung, komplexe Runtime-/Feature-Abhängigkeiten.
