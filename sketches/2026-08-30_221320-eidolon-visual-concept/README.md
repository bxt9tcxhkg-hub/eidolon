## Variant: Eidolon visual concept

### Design stance
Leitstand zuerst, Studio danach: ein ruhiger, dichter Arbeitsleitstand mit Mission Control als Zentrum.

### Key choices
- Layout: linke ruhige Navigation, dominante Mission links, operative Kontrollspalte rechts
- Typography: große Missionsüberschrift, kompakte operative Metadaten
- Color: dunkle, reife Grundfläche mit semantischen Akzenten für active / approval / blocker
- Interaction: sichtbare Fokusobjekte statt Dashboard-KPI-Wand

### Trade-offs
- Stark bei: Lesbarkeit laufender Arbeit, realen Zuständen, Pods, Entscheidungen
- Schwach bei: spielerischer Kreativität, lockerer Whiteboard-Ästhetik, Marketing-Warmth

### Best for
- Ein agentisches System, das echte Arbeit, Eingriffe, Beweise und Child-Runs sichtbar führen soll.
