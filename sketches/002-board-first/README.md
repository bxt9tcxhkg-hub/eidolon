## Variant: Board first

### Design stance
Das Projekt wird als operativer Arbeitsfluss verstanden; der Graph ist unterstützend, nicht zentral.

### Key choices
- Layout: Kanban steht im Zentrum, Graph-Summary nur als Mini-Panel
- Typography: dichter, produktiver, tool-artig
- Color: Statusspalten mit klaren Akzenten
- Interaction: Karten schieben, Fokus auf nächste ausführbare Arbeit

### Trade-offs
- Stark bei: täglicher Ausführung, Priorisierung, Sicht auf offene Arbeit
- Schwach bei: tiefem Verständnis größerer Abhängigkeitsnetze

### Best for
operative Umsetzung, Sprint-ähnliche Arbeit, Task-Steuerung.
