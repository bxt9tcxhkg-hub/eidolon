## Variant: Hybrid workspace

### Design stance
Ein Projekt ist gleichzeitig Denkraum und Ausführungsraum: Graph, Board und Detailpanel arbeiten zusammen.

### Key choices
- Layout: links Projekt-Navigation, Mitte umschaltbarer Workspace, rechts kontextuelles Detailpanel
- Typography: modern, ruhig, funktional
- Color: zurückhaltend mit wenigen starken Statussignalen
- Interaction: Toggle zwischen Graph/Board/Timeline, selektionsbasiertes Arbeiten

### Trade-offs
- Stark bei: langfristiger Nutzbarkeit, Übersicht plus operative Arbeit
- Schwach bei: maximaler Fokus auf nur eine Darstellungsart

### Best for
Eidolon selbst — weil Planung, Abhängigkeiten, Agentenarbeit und Status gemeinsam sichtbar sein müssen.
