# Root History Archive

Diese Dateien bleiben nur als **historische Referenz** erhalten.

- Sie definieren weder aktuelles Produktsoll noch aktuellen Fortschritt.
- Bei Abweichungen gewinnen aktive Dokumente unter `README.md`, `ARCHITECTURE.md`, `ROADMAP.md` und `docs/`.
- Findings mit Nachfolgedokumenten müssen als `superseded` gelesen werden, nicht als offene Gegenwarts-Lücke.
