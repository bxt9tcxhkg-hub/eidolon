# Findings — aktiver Status und Supersession-Regeln

Diese Sammlung enthält **Audit-Findings**, nicht die kanonische Produktspezifikation.

## Statusregeln
- `verified` = das Finding wurde behoben oder als wahrer Ist-Zustand mit Tests/Code-Evidenz abgesichert.
- `superseded` = das Dokument bleibt nur historisch. Eine neuere Datei trägt die aktuelle Wahrheit.

## Leseregel
1. Für Produktsoll immer `docs/eidolon-specification.md` lesen.
2. Für aktuellen Fortschritt `README.md`, `ARCHITECTURE.md`, `ROADMAP.md` und `docs/eidolon-spec-to-system-mapping.md` lesen.
3. Findings nur als Belegpfad verwenden.
4. Wenn ein Finding `superseded` ist, gilt ausschließlich die unter **Superseded by** genannte Nachfolge-Datei.
